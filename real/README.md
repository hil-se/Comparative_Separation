## Experiments on three real-world datasets

### Datasets
 - [Compas](https://www.kaggle.com/datasets/danofer/compass)
 - [German](https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data)
 - [Story point estimation](https://github.com/awsm-research/gpt2sp/tree/main/sp_dataset/marked_data)

### Classification

Run
```
python classification.py
```
under [src/](./src/).

The results will be generated in [result/classification.csv].

### Regression

Run
```
python regression.py
```
under [src/](./src/).

The results will be generated in [result/regression.csv].
